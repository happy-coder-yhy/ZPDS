# ZPDS 部署依赖清单

> 用途：在**干净机器**上从零搭建 ZPDS 完整运行环境（主环境 + WiLoR 推理环境 + 模型资产 + 密钥配置）。
> 快速部署：直接运行 `scripts/setup_env.ps1`（一键，见 §4）；本文档为详细说明与手工对照。

## 1. 环境拓扑（双环境）

```
ZPDS 根目录（本项目）
├── .venv/                    # 主环境：Python 3.11，数据管线（QC/分段/脱敏/场景/VLM）
│                              #   依赖来源：pyproject.toml（主依赖 + extras）
├── e:/ZSPD/WiLoR/            # WiLoR 源码（CVPR 2025，第三方，需单独 clone）
│   ├── requirements.txt      #   推理依赖清单（不含 torch，见 §2.2）
│   ├── mano_data/            #   MANO 模型（手动放置，需许可）
│   └── pretrained_models/    #   detector.pt + wilor_final.ckpt（自动下载）
├── e:/ZSPD/wilor_env/        # WiLoR 推理环境：Python 3.11 + torch 2.5.1+cu121
└── ZPDS/.env                 # 密钥配置（DASHSCOPE_API_KEY / VLM_MODEL）
```

- 主环境运行一切常规流程；**WiLoR 手部检测**（hands 模块 primary 后端）必须在 `wilor_env` 中运行。
- WiLoR 推理自动 `chdir` 到 `e:/ZSPD/WiLoR/`（模型加载依赖 `./mano_data/` 相对路径），勿改。
- 模型资产下载可离线复用：公司内网如无法直连 HuggingFace/GitHub，可先在外网机器下载后拷贝到目标路径。

## 2. 依赖清单

### 2.1 主环境（.venv）

| 依赖组 | 来源 | 内容 | 必装 |
|---|---|---|---|
| 主依赖 | `pyproject.toml` `[dependencies]` | opencv-python / numpy / pandas / pyarrow / pyyaml | ✅ |
| `mcap` extras | `[project.optional-dependencies]` | mcap + protobuf/ros2 + foxglove schemas（遁甲/UMI 必须） | ✅ |
| `hdf5` extras | 同上 | h5py（A2D 必须） | ✅ |
| `hands` extras | 同上 | mediapipe（Hands 模块 MediaPipe 后端） | ✅ |
| `scene` extras | 同上 | torch / torchvision / transformers（场景分割，CPU 也可） | ✅ |
| `privacy` extras | 同上 | ultralytics / easyocr / requests（脱敏必须） | ✅ |
| `dev` extras | 同上 | pytest / pytest-cov / ruff / mypy（开发/测试） | 建议 |

安装命令：`pip install -e ".[mcap,hdf5,hands,scene,privacy,dev]"`

**版本锁定（勿随意升级）**：

| 包 | 约束 | 原因 |
|---|---|---|
| numpy | **< 2** | chumpy 兼容（sitecustomize 补丁恢复 np.bool/np.int 等别名） |
| ultralytics | **== 8.1.34** | 与 WiLoR 需求锁定的版本对齐 |
| opencv-python | ≥4.8 | 中文路径用 `imdecode` 读取；OpenH264 不可用，编码器回退 mp4v |

**numpy 别名补丁**：安装后需把 `sitecustomize.py`（numpy 旧别名恢复脚本）复制到 `<venv>/Lib/site-packages/sitecustomize.py`（`setup_env.ps1` 自动完成；手工部署时从现有环境复制或参照 WiLoR 仓库的补丁）。

### 2.2 WiLoR 推理环境（wilor_env）

| 依赖 | 版本 | 说明 |
|---|---|---|
| Python | 3.11.x | 与主环境一致 |
| torch / torchvision | 2.5.1+cu121 / 0.20.1+cu121 | **不在 WiLoR requirements.txt 内**，需单独安装：`pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cu121` |
| WiLoR requirements.txt | 全部 | 含 `chumpy @ git+https://github.com/mattloper/chumpy`（自动），其余 smplx==0.1.28 / ultralytics==8.1.34 / pyrender 等 |
| numpy 别名补丁 | — | 与主环境相同（sitecustomize.py 复制） |

> 已装验证基线（当前机器）：torch 2.5.1+cu121、numpy 1.26.4、ultralytics 8.1.34、pyrender 0.1.45、chumpy 0.70。

### 2.3 .env 密钥配置（ZPDS/.env）

| 变量 | 必填 | 说明 |
|---|---|---|
| `DASHSCOPE_API_KEY` | 是（VLM/脱敏 PII 需要） | 阿里云 DashScope API Key |
| `VLM_MODEL` | 是（VLM 复核需要） | 场景 VLM 复核模型名（如 `qwen-vl-max`） |

`setup_env.ps1` 会在 `.env` 缺失时生成模板（占位符），**密钥需人工填写**。密钥只在服务端读取，不入库不入响应。

## 4. 一键部署

```powershell
# 从 ZPDS 根目录（或任意位置，脚本自动定位）：
powershell -ExecutionPolicy Bypass -File scripts/setup_env.ps1

# 常用选项：
-Force          # 重建已存在的 venv 并重装依赖（默认复用）
-SkipModels     # 跳过模型下载（网络受限时）
-SkipWilor      # 跳过 wilor_env 与 WiLoR 模型（只需要主环境时）
-WilorRoot "D:/WiLoR"       # WiLoR 源码位置（默认 E:/ZSPD/WiLoR）
-WilorEnvRoot "D:/wilor_env" # WiLoR 推理 venv 位置（默认 E:/ZSPD/wilor_env，位于项目根之外）
-PythonExe "py -3.11"       # 指定 Python（默认自动探测：优先 3.11）
```

> 幂等性：所有步骤已存在即跳过（模型文件存在即不重下；`-Force` 才强制重装/重下）。
> 模型下载失败不会终止部署（降级为警告），可稍后重试或外网拷贝。

脚本执行内容（均幂等，已存在则跳过）：

1. 定位 ZPDS 根目录、检查 Python 3.11（可用 `-PythonExe` 指定）。
2. 创建主环境 `.venv` → `pip install -e ".[mcap,hdf5,hands,scene,privacy,dev]"` → 复制 numpy 别名补丁。
3. 创建 `wilor_env` → 安装 torch 2.5.1+cu121 → `pip install -r <WiLoR>/requirements.txt` → 复制补丁。
4. 模型：WiLoR 模型（调用 download_wilor_models.ps1）+ 脱敏模型（HuggingFace/ultralytics 下载）。
5. `.env` 缺失时生成模板。
6. 自检：主环境 import 检查、torch 版本检查、WiLoR 资产预检（`check_wilor_readiness`）。


## 6. 常见坑

| 坑 | 现象 | 处理 |
|---|---|---|
| numpy 2.x | chumpy 报 `'numpy' has no attribute 'bool'` | 锁定 numpy<2 + sitecustomize 补丁 |
| torch 版本不符 | WiLoR 加载报错 | wilor_env 必须 2.5.1+cu121（requirements.txt 不含 torch，需单独装） |
| cwd 漂移 | `ModuleNotFoundError: wilor` | WiLoR 推理必须在 wilor_env 且由代码自动 chdir；勿手工改动 |
| OpenH264 缺失 | 转码 H264 失败 | 编码器回退 mp4v（已内置），无需处理 |
| MANO 缺失 | WiLoR 推理报 mano_data 找不到 | 从 MANO 官网申请并放置到 `e:/ZSPD/WiLoR/mano_data/` |
| 中文路径 | cv2.VideoCapture 读不到 | 代码已用 `open()`+`imdecode()` 规避；部署路径勿用全角字符 |
| 公网限制 | 模型下载失败/卡住 | HuggingFace/GitHub 国内直连不通：先设 `HTTPS_PROXY` 环境变量重试；或 `-SkipModels` 跳过，外网下载后手动拷贝到目标路径（§3 表）。模型已存在时脚本直接跳过，不会重新联网 |
